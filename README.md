🚌 Wayvo
Tu ciudad, tu ruta.

Wayvo es un proyecto de grado enfocado en la movilidad urbana inteligente. Es una aplicación web adaptable a celulares que permite explorar un mapa, consultar recorridos de demostración y recibir recomendaciones para desplazarse de un origen a un destino.

Desarrollado en Medellín, Colombia.

Funcionalidades
- Mapa interactivo con OpenStreetMap.
- Ruta Express para consultar recorridos.
- Asistente conversacional Wayvo IA.
- GPS y geolocalización.
- Inicio de sesión con Google y Wayvo.
- Panel administrativo y seguimiento de buses.
